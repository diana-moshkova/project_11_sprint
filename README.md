# Автотест для API Яндекс Самоката

Проект содержит автоматизированный тест для проверки получения данных о заказе по номеру трека.

## Содержимое
* `configuration.py` — URL сервера и пути запросов.
* `data.py` — тестовые данные заказа.
* `sender_stand_request.py` — функции отправки HTTP‑запросов.
* `checking_order_track.py` — тест по чек‑листу (1 проверка).
* `.gitignore` — игнорируемые файлы.
* `README.md` — текущая документация.


## Запуск тестов
1. Установите зависимости: `pip install pytest requests`.
2. Запустите тест: `python -m pytest -v checking_order_track`.
3. Ожидаемый результат:
   * 1 тест PASSED (позитивный сценарий, статус  200).
